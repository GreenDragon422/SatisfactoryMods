# Satisfactory Mods

Source code and assets for my Satisfactory mods.

This repository is a curated public export of the development workspace. Generated binaries, build output, local tooling, and other development-only files are not included.

## Mods

### [Belt Purge](BeltPurge)

Destructively clears a connected conveyor network and the fed machine inputs connected to that network.

### [Codex Bridge](CodexBridge)

Provides a reliable local bridge between Satisfactory and Codex Desktop, including the in-game mod and its companion application.

### [Conveyor Signs](ConveyorSigns)

Adds centered wall-sign attachment positions to the left, right, and rear faces of vanilla Conveyor Lift input housings. The configured sign is mirrored on the matching face of the output housing.

### [PathFinder](PathFinder)

Provides vehicle pathfinding debugging tools for tracing routes and visualizing useful A* pathfinding information.

### [Truck Station Signs](TruckStationSigns)

Displays the player-assigned name of each standard or Fluid Truck Station on a centered vanilla sign at the front of the station.

## Repository contents

Each mod directory contains the source files, configuration, content, resources, and runtime components selected for public publication. Development happens in a separate private workspace; this repository is updated only through its curated publishing workflow.
